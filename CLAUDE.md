# Claude Project Instructions

## Start of Every Session

Before doing any work:

1. Read `docs/PROJECT.md`
2. Read `docs/DECISIONS.md`
3. Read `docs/PROGRESS.md`
4. Read `docs/TODO.md`
5. Inspect relevant existing files before making changes.

Use these files as the persistent project memory.

## Working Rules

- Understand the existing project before modifying it.
- Reuse existing patterns, components, and conventions whenever possible.
- Do not change previously confirmed decisions without explaining why.
- Do not assume unfinished work is complete.
- Keep changes focused and reviewable.
- Record important new decisions in `docs/DECISIONS.md`.
- Keep project documentation concise and useful.
- If project information conflicts with existing documentation, surface the conflict before making a major assumption.

## Progress Management

During work:

- Update TODO items when their status changes.
- Record important decisions when they are confirmed.
- Keep `PROGRESS.md` focused on the current state rather than a full history.

## End of Every Session

Before ending a meaningful work session:

1. Update `docs/PROGRESS.md`.
2. Update `docs/TODO.md`.
3. Record important decisions in `docs/DECISIONS.md`.
4. Remove or mark completed TODO items.
5. Write a clear `Next Action` in `PROGRESS.md`.

The goal is that another AI agent can continue the project without needing the previous conversation.
