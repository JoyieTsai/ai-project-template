# AI Agent Project Instructions

This project uses persistent project memory.

## Start of Every Session

Before starting work, read:

1. `docs/PROJECT.md`
2. `docs/DECISIONS.md`
3. `docs/PROGRESS.md`
4. `docs/TODO.md`

## Rules

- Inspect existing work before making changes.
- Follow existing project conventions.
- Respect decisions recorded in `DECISIONS.md`.
- Do not silently reverse previous decisions.
- Keep changes focused and reviewable.
- Update project memory after meaningful work.
- Surface conflicts between the request and documented decisions before making major changes.

## Before Ending Work

Update:

- `PROGRESS.md` — current project state and next action
- `TODO.md` — remaining work and priorities
- `DECISIONS.md` — newly confirmed important decisions

Always leave a clear next action so another agent can continue the work without relying on previous conversation history.
